==========================================
IMAGE SPECIFICATIONS
==========================================

✓ Format: JPG for photos, PNG for logos
✓ Size: Minimum 800x600px for gallery images
✓ Orientation: Landscape (horizontal) preferred
✓ Quality: High-resolution, well-lit photos
✓ File size: Compress to under 500KB per image
✓ Naming: Use lowercase, hyphens instead of spaces

==========================================
IMAGE TIPS
==========================================

✓ Take photos in good lighting (natural light is best)
✓ Show completed projects, not work in progress
✓ Clean and style the space before photographing
✓ Multiple angles of the same project work well
✓ Show before/after where possible
✓ Include variety of your services
✓ Avoid blurry or poorly lit photos
✓ Remove any personal information from photos

==========================================
IMAGE COMPRESSION
==========================================

Before uploading, compress your images:

Online Tools:
- https://tinypng.com (recommended, easy to use)
- https://compressor.io
- https://imagecompressor.com

Desktop Tools:
- Adobe Photoshop (Save for Web)
- GIMP (free alternative)
- IrfanView (Windows)

Target: Keep images under 500KB for fast loading

==========================================
HOW TO UPDATE IMAGES IN HTML
==========================================

After adding images, update index.html:

1. Find the service card section
2. Replace placeholder image path with your image:
   
   FROM: src="images/kitchen/kitchen-placeholder.jpg"
   TO:   src="images/kitchen/your-image-name.jpg"

3. For gallery images, add new items:
   
   <div class="gallery-item" data-category="kitchens">
       <img src="images/kitchen/your-image.jpg" alt="Description">
       <div class="gallery-overlay">
           <h4>Project Title</h4>
           <p>Brief description</p>
           <i class="fas fa-search-plus"></i>
       </div>
   </div>

==========================================
TESTING YOUR IMAGES
==========================================

After adding images:

1. Open index.html in browser
2. Check all images load correctly
3. Test gallery filtering
4. Click images to test lightbox
5. Check mobile display
6. Verify image quality and loading speed

==========================================
TROUBLESHOOTING
==========================================

Images not showing?
✓ Check file names match exactly (case-sensitive)
✓ Verify images are in correct folders
✓ Ensure file extensions are correct (.jpg, .png)
✓ Check image paths in HTML

Images loading slowly?
✓ Compress images (aim for under 500KB)
✓ Use JPG for photos (smaller than PNG)
✓ Optimize before uploading
