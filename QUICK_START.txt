STEP 8: DEPLOY YOUR WEBSITE
==================================================

OPTION A: GitHub Pages (FREE)
------------------------------
1. Create account: github.com
2. Create new repository
3. Upload all files
4. Settings → Pages → Enable
5. Live at: yourusername.github.io/repo-name

OPTION B: Netlify (EASIEST)
----------------------------
1. Go to: netlify.com
2. Sign up (free)
3. Drag & drop your folder
4. Instant deployment!
5. Free domain: yoursite.netlify.app

OPTION C: Your Own Hosting
---------------------------
1. Upload via FTP or cPanel
2. Put files in public_html or www
3. Ensure index.html is in root
4. Visit your domain
